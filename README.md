# モールス受信トレーナー (study_morse)

アマチュア無線の CW (モールス) を「満足に聞き取れる」ようになるための、スマホ向け練習アプリです。
PWA (Progressive Web App) として作っているので、Android の Chrome で「アプリをインストール」すればホーム画面から起動でき、一度読み込めばオフラインで動きます。音の合成・採点・成績の保存はすべて端末の中で行います。

## できること

| 画面 | 内容 |
| --- | --- |
| Koch 法 講座 | 実用的な文字速度 (初期値 20 WPM) のまま 2 文字 (K, M) から始め、正答率 90% で 1 文字ずつ追加。全 43 レッスン (英字・数字・記号・AR/SK/KN)。合格判定は、グループを止めずに流して最後に採点する「まとめて聞く」で行う。「1 グループずつ」は確認用 (音が終わって 1.5 秒で締め切り、答える前の聞き直し不可、合格判定なし) |
| 瞬時認識ドリル | 1 文字を聞いた瞬間にキーを押す。反応時間を計測し、遅い文字・間違えやすい文字を多めに出題 |
| 単語・略語 | CQ・DE・TNX・QTH・73 などの交信用語と英単語。習得済みの文字だけで出題する設定や、聞くだけ (答えを表示・読み上げ) モードあり |
| コールサイン | JA・海外局のコールサイン。正解で +2 WPM / 不正解で −2 WPM の速度可変モード |
| 交信 (QSO) | CQ / 自分の CQ に応答が来る / 定型 QSO (ラバースタンプ) / コンテスト / 海外局 の 5 場面。聞いたあと、コールサイン・RST・名前・QTH などを答える。全文と日本語訳、略語の意味つき |
| 受信環境 | バンドノイズ (CW フィルタ風)・フェージング (QSB)・混信 (QRM)・手送りのクセを合成 |
| 資料 | 符号表 (タップで再生)、略語・Q 符号の意味、交信の流れ、学習ガイド |
| 記録 | 文字ごとの正答率・反応時間、よくある聞き間違え、練習時間、連続日数 |

文字の入力には専用のキーパッドを使います (スマホ標準キーボードの予測変換や、キーボードで画面が隠れる問題を避けるため)。Koch 講座では、そのレッスンで使う文字だけが大きなキーで並びます。

## スマホに入れる (Android)

公開後 (下の「公開の手順」を参照) に次の操作をします。

1. Android の Chrome で `https://nozomisuzuk.github.io/study_morse/` を開く
2. メニュー (︙) →「アプリをインストール」または「ホーム画面に追加」
3. ホーム画面のアイコンから起動。2 回目以降はオフラインでも動きます

新しい版は、ネットにつながっているときにアプリを開いたり、バックグラウンドから戻ったりすると自動で取り込まれ、画面が一度読み込み直されて切り替わります (練習の途中なら、練習画面を出たときに切り替えます)。設定画面の一番下にある「アップデートを確認」でも確認できます。

成績は端末のブラウザ内 (localStorage) に保存されます。Chrome のサイトデータを消すと消えるので、機種変更の前などは「設定 → バックアップを書き出す」で保存してください。

## 公開の手順 (最初に 1 回だけ)

GitHub の無料プランでは、GitHub Pages は public リポジトリでしか使えません。

1. リポジトリの **Settings → General → Danger Zone → Change repository visibility** で public にする
2. **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にする
3. この作業ブランチを `main` にマージする

`main` に push されるたびに `.github/workflows/deploy.yml` がテスト・ビルドして自動で公開します (main 以外のブランチではテストとビルドだけ行います)。

## おすすめの進め方

1. **Koch 法 講座** を 1 日 10〜20 分。間違えても止まらず次の文字へ。正答率 90% で次のレッスンへ
2. レッスンの合間に **瞬時認識ドリル** (反応時間 0.5 秒以内が目標)
3. 文字が増えてきたら **単語・略語** (「習得済みの文字だけ」で)
4. 全文字を覚えたら **コールサイン** → **交信** (CQ → 呼ばれる → 定型 QSO → コンテスト)。最初は「見ながら聞く」
5. 慣れたら設定で **実効速度** を 1〜2 WPM ずつ上げ、**受信環境** を「普通」→「厳しい」に

詳しい理由はアプリ内の「資料 → 学習ガイド」に書いています。

## しくみのメモ

- **速度 (PARIS 方式)**: 1 単位 = 1.2 / WPM 秒。短点 1、長点 3、符号内の間隔 1、文字間 3、語間 7 単位
- **実効速度 (Farnsworth)**: 符号部分 (PARIS の 31 単位) は文字速度のまま、残り 19 単位を引き伸ばして 1 語が 60 / 実効WPM 秒になるようにしています。Farnsworth 単位 `fu = (60/s − 31 × 1.2/c) / 19`、文字間 `3fu`、語間 `7fu` (c: 文字速度, s: 実効速度)。ARRL の Farnsworth 規格 (J. Bloom, KE3Z) の式 `ta = (60c − 37.2s)/(sc)`, `tc = 3ta/19`, `tw = 7ta/19` と一致することを sympy で確認済み (ARRL の原典は直接開けなかったため、式の形は「Bloom の式と同じ結果になる」と明記している morsecode.world の解説で照合)。テスト (`tests/timing.test.ts`) でも PARIS が 60/s 秒になることを確かめています
- **音**: Web Audio API。サンプルを JavaScript で直接合成し、キーイングの立ち上がり・立ち下がりを raised-cosine で整形してクリック音を抑えています (初期値 5 ms)
- **ノイズ**: 白色雑音に中心周波数 = 音の高さ、帯域約 550 Hz のバンドパスを 2 段かけた「CW フィルタを通したバンドノイズ」
- **採点**: 送信文と入力を Levenshtein 距離で整列し、正答率 = (文字数 − 誤り数) / 文字数
- **出題の重み**: 文字ごとの最近の正答率 (指数移動平均) と反応時間から、苦手な文字ほど多く出題
- **Koch の文字順**: LCWO (Learn CW Online) の順序 `K M U R E S N A P T L W I . J Z = F O Y , V G 5 / Q 9 2 H 3 8 B ? 4 7 C 1 D 6 0 X` に、交信で必須の AR・SK・KN を追加しています。先頭部分は検索で照合しましたが、後半は一次情報 (lcwo.net) を直接確認できていないため、細部が LCWO と異なる可能性があります。なお Koch 法は特定の文字順そのものではなく「文字を少しずつ導入する方法」だと説明されています (Long Island CW Club の解説より)

## 注意

- 反応時間は、端末が報告する出力遅延を差し引いて計っていますが、Bluetooth イヤホンなどでは実際より長めに出ることがあります
- 練習中は画面が消えないようにしています (設定で変更可)。画面を消すと再生が止まる場合があります
- コンテストのナンバー (都府県支庁ナンバー・空中線電力の記号) は聞き取り練習用にランダムに作っています。実際の番号の割り当ては各コンテストの規約を確認してください

## 開発

```bash
npm ci
npm run dev        # 開発サーバー
npm test           # ユニットテスト (Vitest)
npm run build      # 型チェック + 本番ビルド (dist/)
BASE_PATH=/study_morse/ npm run build && npm run e2e   # スマホ幅の Chromium で操作テスト (Playwright が必要。Node.js 22.23 で確認)
npm run test:update  # PWA の更新 (新しい版への切り替え) のテスト (Playwright が必要)
npm run icons      # アイコン PNG の再生成
```

E2E テストは、ページ内で再生される音声バッファをモールス解読し、その結果をキーパッドで入力して採点・レッスン解放・オフライン起動までを確かめます。

構成: Vite + Preact + TypeScript、PWA は vite-plugin-pwa (Workbox)。

```
src/core/     符号表・タイミング・音声合成・採点・出題生成 (ブラウザに依存しない純粋なロジック、テスト対象)
src/audio/    Web Audio での再生、画面の消灯防止、読み上げ
src/state/    設定と成績の保存 (localStorage)
src/ui/       画面とコンポーネント
tests/        ユニットテスト
scripts/      アイコン生成・E2E テスト
```
